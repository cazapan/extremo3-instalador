# Extremo 3 · Instalador Windows

[Descargar desde Releases](https://github.com/cazapan/extremo3-instalador/releases)

Ejecutar el EXE, cerrar Minecraft y el launcher, y pulsar **Instalar**. Descargas verificadas del mod, Java 21 y NeoForge para Minecraft 1.21.1. Instancias aisladas. No solicita credenciales.

Compatibilidad automática: launcher oficial y Prism. Otros launchers disponen de preparación manual. [Instrucciones, compilación y límites](LEEME.md).
